# CRUD Simples com Laravel 🚀

Este projeto é um exercício de estudo para aprender e praticar o framework Laravel. 🧠

## Objetivo 📌
- Criar uma aplicação simples com operações de CRUD.
- Explorar rotas, controllers, models e views no Laravel.
- Praticar organização de projeto e integração com frontend.

## Stack 🛠️
- Laravel
- PHP
- Vite
- React

## Como executar ▶️
1. Acesse a pasta `backend` e configure o ambiente.
2. Execute `php artisan serve`.
3. Em outra sessão, rode `npm run dev` na pasta `frontend`.

## Observação 📝
Este README foi escrito para fins de estudo e prática com o framework Laravel.
